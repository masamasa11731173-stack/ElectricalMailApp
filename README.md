# 電気工事依頼メール作成アプリ (ElectricalMailApp)

協力会社への電気工事依頼メールを、工事分類・工事種類ごとの定型項目に沿って効率よく作成し、Microsoft Outlook（従来版）の下書き画面へ自動反映するデスクトップアプリケーションです。

## 主な機能

- **複数工事の一括まとめ作成**
  - 1通のメールに複数の工事内容を登録・複製・編集してまとめられます。
- **工事分類・工事種類別の動的入力フォーム**
  - モータ・回転機、照明設備、電源・コンセント、配電盤・MCC、制御・操作機器など12分類・70種類以上の工事種別を初期搭載しています。
  - 選択した工事種類に応じて専用入力項目（モータ容量、解線日、盤名称、ケーブル仕様など）が自動で切り替わります。
  - 過去の工事件名から工事種類候補を提案する補助機能も備えています。
- **マスタ管理・定型文カスタマイズ**
  - 工事種類・専用項目の追加・編集・削除
  - 協力会社（会社名・担当者・宛先・CC）の登録・管理
  - 件名・冒頭文・末尾文テンプレート（`{会社名}`、`{担当者}`、`{工事概要}` 変数対応）の編集
- **プレビュー＆Outlook連携**
  - 送信前に件名・本文をプレビュー画面で直接編集・再生成できます。
  - 宛先・CC・件名・本文・添付ファイルをセットした状態で Outlook の新規メール画面を表示します（自動送信は行わず、既存の Outlook 署名も保持されます）。
- **作成履歴の保存・閲覧**
  - 作成した依頼メールの履歴をローカルデータベースに保存し、後から内容を確認できます。

## 動作環境

- **OS**: Windows 10 / 11（Outlook 連携機能を使用する場合）
  - ※ 画面表示・データ管理機能は macOS / Linux でも動作しますが、Outlook メール作成機能は Windows の従来版 Outlook（COM 連携）が必要です。
- **Python**: Python 3.10 以上推奨
- **必要なライブラリ**:
  - `PySide6`
  - `pywin32`（Windows で Outlook 連携を使用する場合）
